# TKG Meetings

Talking points for The Koka Group team meetings, one file per meeting, in `meetings/`.

- Written to be read on a phone: short headers, bullets, numbered steps, and scripts in quotes.
- Anything still open (a date, a percentage, an amount) is marked in square brackets, like `[date: TBD]`.
- File names start with the month the meeting is for, then what it is about.

| File | Meeting |
| --- | --- |
| `meetings/2026-11-comp-increase-and-housekeeping.md` | Comp increase, cash bonuses, building the business, who writes a policy, the underwriting script |
